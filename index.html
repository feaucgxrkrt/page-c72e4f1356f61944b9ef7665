使用场景

跨境办公与会议

文档同步、远程桌面和多方会议对延迟抖动更敏感。芳乃家旗舰版与团队版提供更干净的出口策略，减少因公共线路拥塞导致的重连。团队版可按域名或网段做定制路由，把加速范围限制在必要应用。

流媒体与资料访问

基础版提供基础流媒体解锁，适合偶尔点播。旗舰版强调全节点原生解锁，降低因中转链路被识别而失败的概率。学术资料站、软件源与设计素材库同样走订阅节点，按流量计费，便于控制成本。

游戏加速与多设备家庭

IPLC 专线优化主要体现在对延迟稳定要求更高的对战与更新下载。家庭或宿舍多终端同时在线时，请按设备上限选择档位：三人轻度使用可选基础版，五台常用设备建议旗舰版，工作室机房再考虑团队版的 20 台额度与专属客户经理。

操作说明

一、确认套餐与设备数量

打开本页套餐对比，核对每月流量、同时在线台数以及是否需要 IPLC 或定制路由。选定后记录档位名称，后续工单沟通时只需提供订阅前缀，不必发送完整链接。

二、获取机场订阅地址

开通完成后，在用户中心复制订阅 URL。该地址用于客户端自动拉取节点，请保存在本地密码管理器，不要发到群聊或公开收藏夹。

三、安装客户端并导入

按系统选择客户端（见下载章节）。打开应用，选择“从 URL 更新 / 导入订阅”，粘贴地址，等待节点列表刷新。首次连接建议选择标注延迟较低的普通节点做连通性验证，再切换到流媒体或游戏分组。

四、连接、分流与日常维护

开启系统代理或 TUN 模式后，浏览目标站点验证。若某条线路失败，切换同分组其他节点即可，不必反复重装。订阅一般每日自动更新；若节点为空，优先检查本地时间、系统代理冲突，以及当月流量是否用尽。

客户端下载

芳乃家官方下载入口按平台给出适配说明。本站不托管来路不明的安装包，请使用正版系统应用商店或客户端项目的正式发布页，再导入芳乃家订阅。

桌面端

Windows 与 macOS 可使用图形化代理客户端或 Clash 兼容内核。导入订阅后，开启“系统代理”即可覆盖浏览器与多数应用。若公司软件走独立网络栈，需在客户端中打开增强模式。

移动端

Android 使用支持订阅的通用代理应用；iOS 使用兼容描述文件或商店内可导入订阅的客户端。移动网络下建议关闭无用的 UDP 转发以节省流量。同一订阅可在套餐设备上限内多端登录。

导入后检查清单

1. 节点列表非空；2. 系统时间准确；3. 没有第二个全局代理同时开启；4. 流媒体分组与游戏分组分开选择。完成以上四项，再判断线路质量，避免把配置问题当成节点故障。

常见问题

芳乃家官网可以下载哪些客户端？

芳乃家支持 Windows、macOS、Android、iOS 以及 Clash 兼容核心。请先在本页阅读平台说明，再从正式发布渠道获取安装包，最后把机场订阅 URL 粘贴进客户端。官网不提供来源不明的打包文件。

机场订阅链接应该怎样导入？

复制用户中心中的订阅地址，在客户端选择从 URL 更新或导入订阅，确认更新成功后选择节点连接。不要把完整链接发到社交软件。若更新失败，检查是否用了 HTTPS 复制完整、本地时间是否正确，以及套餐是否仍在有效期。

三个套餐的流量和设备数如何计算？

基础版每月 100GB、3 台同时在线；旗舰版每月 300GB、5 台；团队版每月 1000GB、20 台。流量按自然月重置。同时在线以仍保持握手的会话为准，闲置设备请在客户端断开。年付只改变付款周期，不把全年流量一次性汇总使用。

能否稳定解锁常见流媒体平台？

旗舰版与团队版采用全节点原生流媒体解锁策略，覆盖常见影视与音乐服务。基础版提供基础解锁，高峰期可能受线路负载影响。解锁结果会随平台策略变化，请以客户端内实际播放检测为准，不要只看节点名称。

游戏场景为什么要提到 IPLC？

IPLC 专线用于降低国际段的抖动，更适合对延迟稳定有要求的对战与更新。该能力包含在旗舰版与更高档位中。若你只是网页浏览，普通线路节点池通常已经足够，不必为游戏优化单独支付更高档。

流量用尽或设备超限会怎样？

高速流量用尽后，当月将降速或暂停极速通道，次月重置。设备超限时新会话无法建立，断开闲置终端或升级档位即可。团队版另提供 VIP 高带宽节点与专属客户经理，适合把加速当作办公基础设施的团队。

如何联系芳乃家而不泄露订阅？

旗舰版含 7x24 优先工单，团队版含专属客户经理。提交问题时只发送订阅前缀、操作系统、客户端名称和报错原文，不要粘贴完整订阅 URL。芳乃家只通过官方网站公布的渠道回复，不会以加快开通为由要求额外转账。
